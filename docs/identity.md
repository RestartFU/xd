# xd identity

The xd mark is a stacked terminal pane. The offset rear pane represents durable
sessions that remain available behind the active workspace. The front pane and
prompt identify the product as a developer tool without relying on an `x`
silhouette.

## Source of truth

- Editable one-colour mark: `desktop/assets/icons/xd-mark.svg`
- Desktop and Linux app tile: `data/icons/hicolor/scalable/apps/com.restartfu.Xd.svg`
- Android adaptive foreground: `mobile/androidApp/src/main/res/drawable/ic_launcher_foreground.xml`

Use the mark as one colour on either a light or dark background. The product
accent is `#ff7a55`; the app tile is `#111111`. Do not rotate the mark, arrange
copies into an X, add gradients, or remove the offset rear pane.

The geometry is intentionally asymmetric and remains recognizable at 16, 20,
24, 32, and 64 pixels. The icon is an original project asset, but this design
review is not a trademark clearance.
