# xd identity

The xd mark combines a folder with a terminal prompt. The folder represents the
project and worktree organization at the center of xd; the prompt identifies it
as a developer workspace without relying on an `x` silhouette. This direction
was refined from the owner's supplied folder-terminal reference using original,
deterministic vector geometry.

## Source of truth

- Editable one-colour mark: `desktop/assets/icons/xd-mark.svg`
- Desktop and Linux app tile: `data/icons/hicolor/scalable/apps/com.restartfu.Xd.svg`
- Android adaptive foreground: `mobile/androidApp/src/main/res/drawable/ic_launcher_foreground.xml`

Use the mark as one colour on either a light or dark background. The product
accent is `#ff7a55`; the app tile is `#111111`. Do not rotate the mark, arrange
copies into an X, add gradients, or separate the prompt from the folder.

The asymmetric folder tab and simplified prompt are designed to remain
recognizable at 16, 20, 24, 32, and 64 pixels. The icon is an original project
asset, but this design review is not a trademark clearance.
