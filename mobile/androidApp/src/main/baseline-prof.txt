# Baseline profile for xd's Android app: the code app start, MainActivity,
# the Projects list, opening a chat, the transcript, markdown and code
# rendering, and the composer run, compiled ahead of time on install
# (profileinstaller) rather than interpreted on first use.
#
# Written by hand from the code paths: the Macrobenchmark generator needs a
# device or emulator, which this project's build machines do not have.
# Library code (Compose, coroutines, kotlinx.serialization) ships its own
# profiles, which the build merges with this one. R8 rewrites the names
# for the release build.
